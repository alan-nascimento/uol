# Media shortlist, licences and credits - Phase 1

The brief requires that sources can be cited for any media not created by the
author. Every candidate below was checked for its actual licence, not merely
for being findable. Attribution strings are recorded here so that a credit line
can never be reconstructed from memory later.

Nothing enters the site without an entry in this file, and the validator will
not render an image without alternative text and a credit
(`imageAlt` and `imageCredit` are mandatory whenever `imageUrl` is present).

## Do not use

This section matters more than the shortlist. Each of these is easy to find and
would fail on licensing or on honesty.

**Orkut interface screenshots.** There is no freely licensed screenshot of the
Orkut interface, because the interface is Google's copyright. Specifically,
`File:Aparência visual do 'novo orkut'.png` on Wikimedia Commons carries a
CC BY-SA 2.5 licence declared by the uploader as "own work". **That licence is
invalid at source** - an uploader cannot license Google's interface - and the
file is a candidate for deletion. Do not use it.

**Photographs of the Marco Civil being signed.** The images of that ceremony in
circulation are by Roberto Stuckert Filho for the Presidência and Valter
Campanato for Agência Brasil, and are not on Commons. Agência Brasil material
is normally CC BY 3.0 BR, but no specific photograph's licence was confirmed,
so none is listed. Check the Agência Brasil image bank directly if a photograph
of the signing is wanted.

**Any photograph presented as "the Brazilian internet in the 1990s".** There is
no photograph of the Brazilian internet from that decade on Wikimedia Commons.
Searches for lan houses, telecentros, Embratel and RNP return nothing from the
1990s. Every lan house photograph found dates from 2008 to 2012 - which is
historically correct, since lan houses peaked in the 2000s, but it means a
1990s caption on any of them would be false. Where 1990s imagery is needed, use
period hardware such as the dial-up modems below and caption it honestly as
generic equipment of the era rather than implying it is a Brazilian scene.

threshold of originality for copyright. That is an editorial judgement by

trademark notice. Usable in academic work, with the caveat recorded.

## Attribution on the page

Every CC BY and CC BY-SA image requires visible attribution. The credit string
from this file goes into the record's `imageCredit` field, and the template
renders it beneath the image. Because `imageCredit` is mandatory whenever
`imageUrl` is present, an image cannot be published without one.
